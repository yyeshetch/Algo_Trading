## 1. Why study this move?

HFCL is a near-textbook example of a **post-base stage-2 breakout** that
coincided with a fundamental inflection (Q4 earnings turnaround + record
order book + landmark export contract). It's the kind of setup that recurs
every cycle in Indian markets — railways (RVNL/IRCON, 2023), defence
(MAZDOCK/BEL, 2024), PSUs (REC/PFC, 2023). Documenting the signature gives
us a reusable detection template.

### 2.2 Pattern recognition

**Sequence:** Long base → news-led breakout (with confirmation volume) →
earnings-driven gap → mid-trend flag → continuation.
This is **CANSLIM** / **Stage-2** / **Volatility-Contraction-Pattern (VCP)**
behaviour — well-known but rare. It only forms when:

1. A 3+ month base sets a low-volatility floor.
2. A real fundamental catalyst lights the fuse.
3. Volume confirms each leg (not isolated spikes).

## 4. The "HFCL DNA" — extractable signal pattern

The combination below is what made this detectable **before** the move
fully matured (specifically, between the 30-Apr gap and the 25-May leg up).

| Component | Threshold seen on HFCL | Generalised filter |
|---|---|---|
| **Base quality** | 90-day CV ~6% (pre-Apr) | CV ≤ 10% over 60-90 sessions ending ~20 sessions ago |
| **Recent thrust** | 30-day return +68% by 29-May | 30-day return ≥ 20% |
| **Volume surge** | 10d/90d ratio ~5.8× | Ratio ≥ 2.0× |
| **MA stack** | Close > 20DMA > 50DMA > 200DMA throughout May | All three above |
| **52-wk-high proximity** | < 5% from high on most rally days | Within 10% of 52-wk high |
| **Liquidity floor** | 90-day avg turnover > ₹1,000 Cr/day | Min ₹2 Cr/day |
| **Fundamental confirmation** | Q4 rev +128%, order book 2.13×, USD 1.1B contract | Last reported QoQ revenue ≥ +30%, positive PAT swing |

### 4.1 Composite scoring (0..1)

```
score = 0.20 × base_score      # 1 - base_cv / 0.10, clipped 0..1
      + 0.30 × thrust_score    # ret_30d / 0.60, clipped 0..1
      + 0.15 × ma_score        # fraction of {>20DMA, >50DMA, >200DMA} true
      + 0.15 × prox_score      # 1 - pct_below_52wh / 0.10, clipped 0..1
      + 0.20 × vol_score       # (vol_surge - 1) / 3, clipped 0..1
```

HFCL scores **≈ 0.93** on this composite as of 29-May.

## 5. Risks the chart hid

The move had real warning flags that a pure-technical view would miss:

| Risk | Evidence | Mitigation |
|---|---|---|
| **P/E now ~75×** (May 29) | Re-rating exhausted typical fair-value | Trim if revenue growth decelerates QoQ |
| **Order-book execution risk** | ₹21k Cr book includes 6–7 year O&M tail; execution slippage can shift earnings | Track AMC realisations / margin in next 2 quarters |
| **Govt-spend dependency** | BharatNet, defence are policy-driven | Diversification (41% exports) helps, not eliminates |
| **Raw-material volatility** | Fibre/cable margins sensitive to copper/glass | Hedging disclosures in filings |
| **Concentrated single contract** | USD 1.1 Bn export deal is ~50% of order book | Counterparty / FX risk |
| **Late-stage entry** | RSI ~78, >50% above 50-DMA | Position-size accordingly; respect stops |
